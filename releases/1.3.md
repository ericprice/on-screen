# ISO 8601 Kawara 1.3

- Added “White Text” and “Black Text” in their own menu section beneath Reset. White is selected by default; selecting either color deselects the other. Your selection is remembered between launches.
- Use ⌘1 for White Text, ⌘2 for Black Text, and ⌘3 for Custom Text Color.
- Use ⌘T for Custom Text and ⌘R to reset to the current timestamp.
- Added “Custom Text Color…” to choose desktop text colors with the native macOS color picker. Color changes appear immediately, and the chosen color is remembered between launches.
- “Custom Text…” now shows a checkmark when custom text is active. Reset clears it.
